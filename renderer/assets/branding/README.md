# ExOne application branding

- `exone-lion.png` is the transparent in-app/window icon.
- `exone-lion-titlebar-24.png` and `exone-lion-titlebar-48.png` are tightly
  cropped and sharpened 1x/2x sources for the compact 24-pixel title-bar mark.
- `exone-lion.ico` contains 16 through 256 pixel Windows icon sizes.

Both assets use only the lion head extracted from the user's local
`fsd-mod-logo/assets/first-strike-logo-source.png`. The retired source text and
disconnected shield fragments are not included.

The production mark uses a neutral cool-gray field palette that matches the
launcher's graphite interface. No yellow or gold remains. The original geometry
and alpha mask are preserved in the application icon. The title-bar variants
remove only invisible canvas padding before downsampling and sharpening, so the
lion uses the available compact display area instead of becoming a muddy spot.
